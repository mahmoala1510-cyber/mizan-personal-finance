# ميزان

تطبيق مالي شخصي عربي يعمل كتطبيق ويب تقدّمي (PWA) ويمكن تثبيته على أندرويد. يحفظ الحسابات والعمليات والفئات والديون وقائمة الطلبات محليًا على الجهاز باستخدام `localStorage`.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يظهر في الطرفية. لبناء نسخة النشر:

```bash
npm run build
```

## التثبيت على أندرويد

1. انشر مجلد `dist` على استضافة HTTPS مثل Netlify أو Vercel أو GitHub Pages.
2. افتح الرابط في Chrome على أندرويد.
3. اختر **إضافة إلى الشاشة الرئيسية** أو **تثبيت التطبيق** من قائمة المتصفح.
4. من داخل التطبيق افتح زر الجرس وفعّل الإشعارات.

> الإشعارات المحلية تُفحص عند فتح التطبيق. الإرسال في وقت محدد بينما التطبيق مغلق يحتاج تغليفًا أصليًا مثل Capacitor أو خدمة Push بخادم.

## الخصوصية

لا توجد حسابات مستخدمين أو خوادم في هذه النسخة؛ البيانات تبقى في مساحة تخزين المتصفح على الجهاز. حذف بيانات الموقع من إعدادات المتصفح يحذف بيانات التطبيق.
